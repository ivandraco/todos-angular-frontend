# Todos Angular Frontend

Proyecto Angular (v16) ejemplo para consumir la API Spring Boot Todos CRUD.

Pasos:

1. Instalar dependencias:

   npm install

2. Levantar la app (usa el proxy para evitar CORS):

   npm start

3. Asegúrate de tener el backend Spring Boot corriendo en http://localhost:8080


Endpoints usados: /api/todos
